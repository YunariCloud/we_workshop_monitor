# 桌面界面参考

本次重做参考了以下 Flutter 开源项目的产品界面组织方式，界面与组件在本项目中自行实现，未复制其代码或品牌素材。

| 项目 | 参考方向 | 本项目的实现 |
| --- | --- | --- |
| [AppFlowy](https://github.com/AppFlowy-IO/AppFlowy) | 桌面工作空间与内容层级 | 紧凑侧栏、面包屑工具栏、独立内容区 |
| [LocalSend](https://github.com/localsend/localsend) | 清晰导航与设置分组 | 统一按钮、查询方式与自动同步分组、自适应窄窗口 |
| [Spotube](https://github.com/team-spotube/spotube) | 媒体封面与资料浏览 | 封面优先的作品网格，移除发光和悬停缩放效果 |

## 外观

- 浅色：近白背景、白色内容面板、低饱和紫色操作按钮。
- 深色：中性炭灰背景、柔和的文字对比、紫色强调。
- 侧栏底部切换主题；偏好保存在非敏感配置中。
- 创作者按列表行呈现，突出名称、归档数、同步状态与操作。
- 主要页面标题 24px，列表名称 14px，辅助信息 10–12px。

## 查询设置

支持自动选择、Web API Key、Steam 客户端、公开网页四种方式。

自动模式在填写 Key 时优先使用 API。显式选择的方式失败后会提示，不自动换成其他来源。API 模式直接读取带认证响应中的完整详情；不同权限来源可能返回不同的作品集合。

Key 继续通过系统安全存储保存，不写入配置 JSON、源码或测试用例。
