# 桌面界面参考

本次重构以 [FlClash](https://github.com/chen08209/FlClash) 的官方桌面预览为主要视觉参考。界面与组件在本项目中自行实现，未复制其源码、品牌或图片素材。

## 页面结构

- 统一侧栏和页面标题，移除面包屑及重复的大标题。窄窗口使用带文字的紧凑导航。
- 概览改为非对称双卡片：作品归档数量与可访问比例、查询方式与同步计划。下面使用一个分组面板管理创作者。
- 设置改为查询与同步、本地备份、WebDAV 云端备份、外观、内容分级五个独立子页面，统一返回导航；查询方式用单选列表，周期用选项按钮，移除下拉与折叠表单。
- 资料库保留封面优先的网格，使用统一圆角与低对比边框。

## 外观

- Material 3 配色、低饱和紫色、带轻微色调的背景和面板。
- 主要面板圆角 24px，输入框与按钮圆角 16px；页面间距 28px，卡片间距 16px。
- 浅色与深色均保留，侧栏和设置页均可切换；偏好保存在非敏感配置中。
- 通用表面与设置行位于 `lib/workspace_widgets.dart`。

## 功能保留

支持自动选择、Web API Key、Steam 客户端、公开网页四种方式。自动模式在填写 Key 时优先使用 API。显式选择的方式失败后会提示，不自动更换来源。

Key 通过系统安全存储保存，不写入配置 JSON、源码或测试用例。保留本地 ZIP、目录镜像，新增 WebDAV 独立子页面；云端默认使用轻量模式，并明确提示动画转静态封面与完整保留元数据。

## 验证

界面测试覆盖 1440×900、960×680、900×700、720×620 四种尺寸和两种主题，包括页面导航、添加作者、设置子页面、API Key 与本地备份入口、主题切换。预览截图使用测试数据，不代表实际同步结果。

## 交互修正

- 圆角表面使用 Material 裁剪，点击、水波纹与悬停反馈受同一轮廓约束。
- 筛选按钮统一主题色，选中与未选中文字在两种主题下均检查至少 4.5:1 的对比度。
- 变更页与作品详情共用连续时间线，只显示事件、作品名和时间；点击后查看字段对比。
- 桌面最小窗口尺寸为 960×680；若启动窗口小于限制，只扩大不足的维度。

## 字体与主题

对照 [FlClash 字体回退实现](https://github.com/chen08209/FlClash/blob/main/lib/common/font.dart) 与 [主题初始化](https://github.com/chen08209/FlClash/blob/main/lib/application.dart)：普通界面使用 Material 默认字体（Windows 为 Roboto），简体中文回退 Microsoft YaHei UI。JetBrainsMono 是其编辑器字体，不用于本项目的普通界面。

主题切换前捕获当前画面，通过 320ms 整页淡出显示新主题，保留当前页面、输入内容和显示筛选；立即应用新外观，不等待配置落盘。

## 创作者与内容分级

- 新数据目录没有内置创作者。重启后显示的作者来自本机 SQLite 的已保存记录，可从创作者菜单移除。
- 添加作者、单独同步时获取头像；已有作者可使用“更新头像”。头像不可获取时保留原头像或显示昵称首字。缓存与本地 ZIP、镜像备份一同保存。
- 按 Everyone / Questionable / Mature 标记映射安全、存疑、成人。多个标记冲突时取更严格的级别；没有明确标记的归为未分级。
- 每次启动只显示安全内容，临时选择不写入持久配置。仅作品资料库应用显示分级，变更记录不受分级、作品库创作者选择及关键词筛选影响，后台进度不展示作品标题。
- 同步、归档统计、数据库、备份不应用显示筛选，继续保存全部可获取作品。分级来自 Steam 标签，不对图片作自动识别。

## 信息层级与时间线

- 基础正文和状态值统一 14px，辅助说明与时间统一 12px；创作者列表使用等高文本行、固定宽度的数量与状态列，日期与状态文字左对齐。
- 变更记录先选择创作者，再查看汇总时间线或作品时间线。作者汇总按同步批次统计建档、新增、修改、下架和恢复数量，点击可查看该次涉及的作品；每件作品有完整独立时间线。
- 汇总先按作者隔离，再按批次分组；作品时间线按作品隔离，不沿用作品库的分级、作者、搜索筛选。历史读取不受默认 300 条列表上限限制。
- 普通界面不展示图片文件名、缓存路径、预览图地址、哈希值和内部接口标识。封面变化只提示已保存或已更新；字段变化使用中文名称，详情按需查看。

## 轻量备份与同步进度

- 轻量转换在后台隔离执行，仅改写私有备份工作目录。以 SQLite 热快照中的作品与历史日志收集有效封面引用，保留其所有版本；静态封面最长边 1280px，JPEG 质量 80；GIF 首帧采用 JPEG/PNG 中更小的静态结果。
- 同步更新备份副本中的封面路径和摘要、作品 JSON、CSV 与数据库校验值；缺失或无法转换的图片不伪造，无法转换时保留原文件。本机数据库和原图不改动。
- WebDAV 使用系统安全存储保存密码，配置页面默认轻量并解释损失的动画效果；上传采用临时名加 MOVE，只有提交成功后写入成功记录。失败清理只针对本次临时文件。未提供服务器凭据时，开发验证使用本地 WebDAV 测试服务器。
- API Key 测试仅发出一次 `numperpage=1` 请求，不触发同步、分页或封面下载。
- 手动与定时同步通过同一调度入口避免重叠。逐作品提交后产生结构化完成数，总数包括远端作品与待核验的本地消失候选；界面只在对应创作者行展示数量，不再使用顶部进度条。
